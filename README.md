# Value at Risk: Equally Weighted AMZN &amp; AAPL Portfolio  A comparison of five Value at Risk (VaR) methodologies on a $100 portfolio split equally between **Amazon (AMZN)** and **Apple (AAPL)** ($50 each). The analysis uses 6 months of daily closing prices (123 return observations) and is implemented in Excel VBA.
